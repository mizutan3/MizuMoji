# MizuMoji

A software tool for character recognition in images based on optical character recognition (OCR) technology. The software tool uses the Tesseract library to perform OCR and also includes image preprocessing functions to improve recognition quality. Several processing stages have been implemented, including gamma correction, contrast enhancement using CLAHE, image binarization, and shadow removal. In addition, the program supports text cleaning and normalization for three languages: English, Ukrainian, and Japanese.
